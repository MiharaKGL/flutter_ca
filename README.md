## SpellAura - Online Bookstore Application

Introduction

Purpose of the Application:
SpellAura is a mobile-based online bookstore application developed using Flutter. The purpose of this
application is to provide users with a simple and interactive platform to browse, select, and purchase
books conveniently. The app is designed with a magical-themed user interface to enhance user
engagement and create a unique reading experience.

Overview of Key Features
- User authentication (Login/Register)
- Browse books by categories
- View list of available books
- Add books to cart
- View cart and total price
- Profile management (view and edit details)
- Smooth navigation between screens

Conclusion
In this project, we successfully developed a Flutter-based online bookstore application named SpellAura. The app demonstrates essential mobile application development concepts such as UI design, navigation, state management, and user interaction. 
Through this project, we gained practical knowledge in:
 - Flutter framework and Dart programming
 - Designing user-friendly interfaces
 - Implementing navigation and user flows
 - Managing application state and user data

One of the main challenges faced was ensuring smooth navigation between screens while maintaining a consistent theme. Additionally, handling user interactions such as cart updates and profile editing required careful implementation. Then we were unable to connect our project to Supabase, as the supabase was updated and did not have enough time to figure out how the new version works. Overall, the project helped us improve both our technical and problem-solving skills.
